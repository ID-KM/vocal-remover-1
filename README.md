
# 🎵 Music Remover 1 — AI Vocal Isolation

> **عزل الصوت من الفيديوهات والمقاطع الصوتية بالذكاء الاصطناعي**

A web application that separates vocals from music using Demucs (Hybrid Transformer Demucs). Upload a file or paste a link, and get clean vocal isolation.

---

## ✨ Features

- **AI Vocal Isolation** — Powered by Demucs (htdemucs), separates vocals from instrumental
- **File Upload** — Drag & drop or browse for MP3/MP4 files
- **URL Download** — Paste a link from YouTube, TikTok, Instagram, SoundCloud, and more
- **Output Formats** — Download isolated vocals as MP3 or MP4 (with original video)

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/ID-KM/music-remover-1.git
cd music-remover-1

# Setup
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run
python app.py
```

Then open `http://localhost:5001` in your browser.

## 📦 Requirements

- Python 3.8+
- FFmpeg
- PyTorch (installed via requirements.txt)

## 🔧 Tech Stack

| Component | Technology |
|-----------|-----------|
| Backend | Flask (Python) |
| AI Model | Demucs (Hybrid Transformer) |
| Frontend | HTML + CSS + JavaScript |
| Media | FFmpeg |
